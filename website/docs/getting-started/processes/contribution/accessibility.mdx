## Accessibility

We follow the **POUR** guidelines for accessibility standards for global code, keyboard
navigation, image and other attributes.

| Principle | Guidance |
| --- | --- |
| Perceivable | 1. Create content that can be presented in different ways, including by assistive technologies, without losing meaning.<br />2. Make it easier for users to see and hear content. |
| Operable | 1. Do not use content that causes seizures or physical reactions.<br />2. Make the UI accessible to people with sight or motor disabilities. |
| Understandable | 1. Make text readable and understandable.<br />2. Make content appear and operate in predictable ways.<br />3. Help users avoid and correct mistakes. |
| Robust | 1. Maximise compatibility with current and future user tools. |
