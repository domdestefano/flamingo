# Design tokens

Flamingo's design tokens are exported directly from Figma Variables and kept
in sync with this site (see [scripts/README-tokens.md](https://github.com/deliveryhero/flamingo/blob/main/scripts/README-tokens.md)
for how the export/sync process works). Every value in the pages under
**Tokens** is a live CSS custom property — use the brand switcher in the
navbar to see brand colours update in real time.

## Token layers

- **Semantic colours** — brand-independent (background, error, success,
  overlay, shadow, neutral). Follow light/dark mode only.
- **Brand colours** — primary, secondary, and illustration colours, unique
  per brand (11 brands supported).
- **Global tokens** — spacing, sizing, corner radius, border thickness,
  opacity, blur, and typography scales. Identical across brands and modes.
