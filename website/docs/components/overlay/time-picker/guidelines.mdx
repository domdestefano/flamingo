# Guidelines

<ComponentTabs basePath="/components/overlay/time-picker" />

## Usage

Use the Time picker whenever the user needs to choose a specific time, e.g. a delivery slot.
Disable hours/minutes outside a valid range (like business hours) rather than letting the user
pick an invalid time and error out afterward.
