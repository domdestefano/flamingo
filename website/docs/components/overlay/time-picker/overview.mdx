## Component

<ComponentImage src="/img/components/time-picker/time-picker-overview.png" alt="Time picker with hour/minute wheels and a Select time action" />

1. 24h time format
2. 12h time format

Time pickers let users select a specific time and live inside bottom sheets, following the same interaction patterns as other overlay components.

- Time pickers let users select a specific time (e.g. filtering sessions in a day).
- Time is selected via scrollable columns for hours, minutes, and AM/PM (for 12h format).
- Hours and minutes scroll in a loop (e.g. after 12 → 00, after 59 → 00); AM/PM does not loop.
- Unavailable hours and minutes can be hidden.
- Tapping the **Now** button scrolls hours and minutes to the current time; when the current time is already selected, the Now button is inactive.
- Users must confirm their selection for the time value to be saved.

## Properties

| Property | Details |
| --- | --- |
| Time format | 24h, to show 00 to 23 hours, in a 2 column layout / 12h, to show 01 to 12 hours in a 3 column format, where the third column is used to select AM or PM. |
| Time intervals | To show intervals of minutes. |
| Time state | **Now**, to show the current time / **Default**, any selectable minute or hour / **Selected**, a time that is currently selected. |
| Stack | To show slots and replace them with other components. |
| Action container | To show or hide the action of the Bottom sheet. |
