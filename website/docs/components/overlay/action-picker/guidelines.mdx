# Guidelines

<ComponentTabs basePath="/components/overlay/action-picker" />

## Usage

Use the Action picker for a plain list of actions the user can pick from — not for custom
supplemental content, which belongs in a Bottom sheet instead.

## Use cases

### Destructive actions

<DoDontTable
  doImage="/img/components/action-picker/action-picker-destructive-do.png"

  dontImage="/img/components/action-picker/action-picker-destructive-dont.png"
