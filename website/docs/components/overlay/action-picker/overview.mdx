## Component

<ComponentImage src="/img/components/action-picker/action-picker-overview.png" alt="Action picker with title, description, actions list, and Cancel" />

Action pickers let the user select an action and live inside bottom sheets, following the same
interaction patterns.

- Actions can be of default type or destructive.
- Title and dismissing button should be always there, while the description is optional.
- They should be used when actions refer to the same category or have equal prominence.
- Actions should never be more than 4, to avoid information overload.

## Properties

| Property | Details |
| --- | --- |
| Number of actions | The range should be from 2 to 4. |
| Action type | Default, for regular actions / Destructive, for actions that delete, remove, or destroy. |
| Dismiss button | To dismiss the Action picker. |

## Action picker vs. Bottom sheet

Action pickers are used for actions of equal prominence or when they refer to a similar category.
Bottom sheets can instead provide more graphic information and apply a different hierarchy to the
actions within them.

## Action picker vs. Option picker

The Action picker lets the user select an action that will trigger something, e.g. "take a photo"
will trigger the camera interface to appear. The Option picker instead lets the user select an
option that represents a preference, e.g. choosing a ringtone among multiple tones, without
immediately triggering anything else.
