# Content

<ComponentTabs basePath="/components/overlay/dialog" />

- The title is mandatory — use it to quickly explain what the dialog is about.
- Use the description to add detail the title doesn't cover; don't restate the title.
- Avoid the phrase "Are you sure...?" or anything that undermines the user's ability to decide.
  State the consequence of the action instead, e.g. "This action will erase all your data."
- Avoid a condescending tone or vague button labels (e.g. plain "OK") — be clear and specific about
  what each action does, e.g. "Contact dispatcher" rather than a generic label.
- Always include a clearly labelled dismissing action, such as "Got it," "Dismiss," or "Cancel."
