# Option picker <StatusBadge status="stable" />

A selection list, e.g. picking a country or a reason for editing a price. Supports selecting a
single option or multiple.

## Properties

| Property | Details |
| --- | --- |
| Selection type | Single option / Multi option. |
| Scrolled state | Whether the option list has been scrolled (changes elevation/header treatment). |
| Show Body | Optional — toggles the description below the title. |
| Show 2nd Button | Optional — toggles the Cancel action. |
