## Properties

| Property | Details |
| --- | --- |
| Selection type | Single, to let the user choose only one option / Multiple, to let the user choose multiple options. |
| Scrolled state | True, when the Bottom sheet's content is scrolling and the header appears / False, when the content is not scrolling or scrollable. |
| Enable Search input | To show or hide the search input. |
| Dismiss button | To dismiss the Option picker. |

## Action picker vs. Option picker

The action picker lets the user select an action that will trigger something, e.g. "take a photo" will trigger the camera interface to appear. The option picker, instead, lets the user select an option that represents a preference, e.g. choosing a ringtone among multiple tones, without immediately triggering anything else.
