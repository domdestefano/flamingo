# Guidelines

<ComponentTabs basePath="/components/overlay/option-picker" />

## Usage

Use single-select mode when picking an option should confirm and dismiss immediately (e.g.
choosing a country). Use multi-select mode when the user needs to pick several options before
confirming — this mode requires an explicit confirm and Cancel action.
