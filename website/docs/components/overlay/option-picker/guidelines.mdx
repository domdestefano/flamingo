# Guidelines

<ComponentTabs basePath="/components/overlay/option-picker" />

## Placement & usage

The option picker sits always at the bottom of the screen. You cannot have an option picker on
top of another — they don't stack.

## Trigger point

Option pickers can be triggered usually by a dropdown or chip, where the selection represents a
preference the user is making. Flamingo recommends showing the choice made by the user through
the triggering element as well, after the option has been selected.

## Usage

Use single-select mode when picking an option should confirm and dismiss immediately (e.g.
choosing a country). Use multi-select mode when the user needs to pick several options before
confirming — this mode requires an explicit confirm and Cancel action.

## Use cases

### Single select main button

When the option picker is single select, the interaction should be fast; therefore the picker
doesn't need a confirmation button — once the option has been selected, the picker disappears.

### Cancel action

The dismissing action should always be present in any option picker, as this serves to cancel the
option selection flow.
