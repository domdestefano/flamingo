# Guidelines

<ComponentTabs basePath="/components/overlay/bottom-sheet" />

## Usage

Use a Bottom sheet for supplemental content or a custom set of actions that doesn't fit the
Action picker's plain list-of-actions pattern. Don't use it just to show a simple list of actions
with icons — see below.

## Use cases
