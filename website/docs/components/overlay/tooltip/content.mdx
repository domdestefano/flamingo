# Content

<ComponentTabs basePath="/components/overlay/tooltip" />

- Keep the message to a single line — tooltips are meant to be a brief, neutral piece of
  information, not a place for detailed explanations.
- If the information doesn't fit on one line, don't shorten it awkwardly — use a bottom sheet or a
  message banner instead.
- Write the message so it makes sense read on its own, since the tooltip may be dismissed after a
  few seconds without further interaction (e.g. "Hot shifts make you earn more money").
