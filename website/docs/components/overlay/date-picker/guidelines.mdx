# Guidelines

<ComponentTabs basePath="/components/overlay/date-picker" />

## Placement & usage

The date picker sits always at the bottom of the screen. **You cannot have a date picker on
top of another, they don't stack.**

### Slots

Date pickers in Flamingo let teams insert other UI elements between the Date view and the
action area. This is done with slots, which are placeholders for other Flamingo components.
We recommend only using slots short enough that provide contextual information, like Message
boxes or Tags.

### Trigger point

Date pickers can be triggered by several elements, the most common ones are buttons, text
inputs, or icon buttons. Flamingo recommends using a calendar icon to indicate that the
action will trigger a Date picker to appear.

When using text inputs, Flamingo advises to also enable the functionality to type in the date
values with the keyboard, plus relying on the icon button (with a calendar icon) to trigger
the Time picker. This way, the user will use the input method of their choice.

### Disabled dates, months and years

When you want to show that a date cannot be selected, we recommend relying on an informative
message in the Stack area. Furthermore, days can be greyed out, while months and years can be
hidden if they cannot be selected.

## Use cases

### Stack usage

Use the Stack to add an informative message to the date selection flow. Be mindful of not
adding too much text to the Message box, in order to avoid scrolling issues — a Tag can also
be used in the Stack to highlight quick, glanceable information about the dates.

### Date format

Due to space limitations, the letter to represent the days in the date at the top of the Date
picker is always single character based. This is to match also what the most common apps and
operating systems do, when handling date formats in calendars.
