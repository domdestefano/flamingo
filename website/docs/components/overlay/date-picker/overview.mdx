## Description

- Lives inside a bottom sheet and follows the same appear/disappear and dismiss behaviour —
  it slides up from the bottom, and can be dismissed by tapping the Scrim (the area outside
  the sheet).
- Month and year scroll in separate columns: month scrolls in a loop (December → January),
  year does not.
- Tapping the **Today** button sets the day, month, and year to the current date; the button
  becomes inactive once today is already selected.
- Users must confirm their selection for the date to be saved.
- The day view is a 7-column grid with 4, 5, or 6 rows, depending on the number of days in
  the month.
- Date ranges are created by selecting a start day and an end day, auto-highlighting the days
  in between; selecting a new day resets the previous range.
- Users can switch between the Day view and the Month and Year view via the top-left button,
  and move between months by tapping the arrow buttons or swiping the calendar view.

## Properties

| Property | Details |
| --- | --- |
| View | **Day**, to show days. **Month and Year**, to show scrollable lists of months and years. |
| Date mode | **Single**, lets the user select a single date only. **Range**, lets the user select a range of dates. |
| Day state | **Today**, **Default**, **Disabled** (weekends, holidays, or a day that cannot be selected), **In range**, **Selected**. |
| Stack | To show slots and replace them with other components. |
| Action container | To show or hide the action of the Bottom sheet. |
