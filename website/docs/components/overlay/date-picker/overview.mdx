## Properties

| Property | Details |
| --- | --- |
| View | Date / Month and Years — switches between the day grid and a month/year selector. |
| Date selection | None / Single (a range mode is also supported per the component description). |
| Show Stack | Optional — toggles an extra content slot below the calendar grid. |
