## Description

Cards are surfaces that display content and actions on a single topic. They should be easy to
scan for relevant and actionable information. Elements, like text and images, should be placed on
them in a way that clearly indicates hierarchy. **A card is identifiable as a single, contained
unit.**

Cards can be of 3 types:

- **Default**, used as default option to encapsulate content. It has a subtle prominence,
  especially on white background.
- **Alternative**, used as an alternative to the default option, when you want to add
  medium-level prominence to the encapsulated content, especially on white background.
- **Elevated**, this should be used when the background is `color.background01` (aka
  background-alternative), and you want to make major prominence to the encapsulated content.

Use cards only when necessary — by default Flamingo recommends a flatter and edge to edge visual
design. Cards should be used only when necessary, specifically to group relevant and actionable
information to scan at a glance. When the content is encapsulated in a card, this needs to have
28px margins all around, while the card is placed at 24px from the edge for the screen. Because of
this, cards widely favor to avoid truncation and clutter.
