## Component

<ComponentImage src="/img/components/empty-screen/empty-screen-overview.png" alt="Empty screen with an illustration, title, and description" />

The Empty Screen is a full-page component designed to communicate to the user when there is no
content to show.

- **Normal use cases**, such as pages where the user has not added or received any content.
- **Error cases**, such as when loading has failed due to a server problem or cellular connection.

It pairs an illustration with a short title and description, and can optionally include one or
two buttons for the next action.

## Properties

| Property | Details |
| --- | --- |
| Graphic block | (Optional) An illustration relevant to the empty state — shown or hidden via `Show Graphic Block`. |
| Title | A short, direct statement of what's empty. |
| Body | (Optional) A short description adding context or next steps. |
| Buttons | (Optional) Zero, one, or two buttons for the next action. |
