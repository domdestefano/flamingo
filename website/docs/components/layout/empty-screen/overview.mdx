# Empty screen <StatusBadge status="stable" />

Communicate that a screen genuinely has nothing to show yet, and what the user can do about it.

## Component

<ComponentImage src="/img/components/empty-screen/empty-screen-overview.png" alt="Empty screen with an illustration, title, and description" />

Use the empty screen when a list, page, or section has no data to show — e.g. no deliveries yet,
no saved addresses. It pairs an illustration with a short title and description, and can optionally
include one or two buttons for the next action.

## Properties

| Property | Details |
| --- | --- |
| Graphic block | (Optional) An illustration relevant to the empty state — shown or hidden via `Show Graphic Block`. |
| Title | A short, direct statement of what's empty. |
| Body | (Optional) A short description adding context or next steps. |
| Buttons | (Optional) Zero, one, or two buttons for the next action. |

### Clickable area

Each button's tappable area meets the standard touch target size, even when both buttons are
placed close together side by side.
