## Component

<ComponentImage src="/img/components/horizontal-divider/horizontal-divider-overview.png" alt="Horizontal divider sizes: thin and extra thick" />

1. Thin — the default weight, for separating rows or sections within the same context.
2. Extra thick — a heavier weight for a stronger visual break between larger sections.

This component's Figma spec doesn't include a separate Anatomy section — the divider is a single
line, described by its size property alone.
