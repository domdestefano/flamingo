## Component

<ComponentImage src="/img/components/vertical-divider/vertical-divider-overview.png" alt="Vertical divider sizes: thin and extra thick" width={400} />

1. Thin — the default weight, for separating items placed side by side (e.g. stats in a row).
2. Extra thick — a heavier weight for a stronger visual break between larger side-by-side sections.

This component's Figma spec doesn't include a separate Anatomy section — the divider is a single
line, described by its size property alone.
