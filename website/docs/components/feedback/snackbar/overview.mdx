## Component

<ComponentImage src="/img/components/snackbar/snackbar-overview.png" alt="Snackbar types (success, alert, error) and with an action button" />

Snackbars inform users of a process the app has performed or will perform. They appear
temporarily, anchored to the bottom of the screen, then dismiss on their own — unlike a Message
box, which is a persistent part of the page.

## Properties

| Property | Details |
| --- | --- |
| Type | **Success**, **Alert**, or **Error** — match the outcome being communicated. |
| Button | (Optional) A single action, like "Undo" or "Retry," shown via `Show Button`. |
