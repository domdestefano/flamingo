# Content

<ComponentTabs basePath="/components/feedback/snackbar" />

- Keep the message to one short line — the snackbar disappears automatically after a few seconds,
  so it needs to be readable at a glance (see Guidelines).
- State what happened plainly — "Name updated successfully," not "Success!"
- If there's an action, use a short, specific label like "Undo" or "Retry" rather than "OK."
