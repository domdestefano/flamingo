# Guidelines

<ComponentTabs basePath="/components/feedback/snackbar" />

## Usage

Use a snackbar to confirm a completed or upcoming action — e.g. "Name updated successfully" — that
the user doesn't need to actively acknowledge. It appears briefly, then dismisses on its own.
