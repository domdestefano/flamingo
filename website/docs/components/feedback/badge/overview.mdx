## Component

<ComponentImage src="/img/components/badge/badge-overview.png" alt="Badge examples: a count, a plain dot, and short labels" width={300} />

Badges are used for communicating secondary or additional information on top of other UI
elements — e.g. the number of unread messages, or the number of filters applied.

## Properties

| Property | Details |
| --- | --- |
| Label | Optional short text or number. When absent, the badge renders as a plain dot. |
