# Guidelines

<ComponentTabs basePath="/components/feedback/badge" />

## Usage

Use the badge to attach a small, secondary piece of information to another element — a count, a
filter indicator, or a plain "new" dot. It's never used on its own, always alongside the element it
refers to.

## Constraints

The component supports more than 3 characters, but its text style shouldn't be changed regardless
of label length.
