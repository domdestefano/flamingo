# Content

<ComponentTabs basePath="/components/feedback/message-box" />

- **Title**: state the situation plainly — "You've reached the cash limit" rather than something
  vague.
- **Body**: keep it to a sentence or two. Explain what happened and, if relevant, what the user can
  do about it — not a full explanation of the underlying system.
- **Button label**: a short action + noun, same as any other button in Flamingo (see the button
  components' Content pages) — e.g. "Add funds," not "Click here to add funds."
