## Component

<ComponentImage src="/img/components/message-box/message-box-overview.png" alt="Message box types: neutral, success, alert, error" />

Message boxes are quite prominent, as they need to draw the user's attention and inform them
about important matters — unlike a Snackbar or Message bar, they're a persistent part of the
page's content, not a temporary overlay.

## Properties

| Property | Details |
| --- | --- |
| Type | **Neutral**, **Success**, **Alert**, or **Error** — match the nature of the information being shown. |
| Prefix | (Optional) An icon or emoji, shown or hidden via `Show Prefix`. |
| Body | (Optional) Supporting text, shown or hidden via `Show Body`. |
| Button | (Optional) A single action button, shown or hidden via `Show Button`. |
