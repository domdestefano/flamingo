Show a prominent piece of information about something that refers to the user or their work.

## Component

<ComponentImage src="/img/components/message-box/message-box-overview.png" alt="Message box types: neutral, success, alert, error" />

Message boxes are quite prominent, as they need to draw the user's attention and inform them
about important matters — unlike a Snackbar or Message bar, they're a persistent part of the
page's content, not a temporary overlay.

## Properties

| Property | Details |
| --- | --- |
| Type | **Neutral**, for information that has not any sort of positive, alerting, or negative connotation. **Success**, for positive information. **Alert**, to convey alert or caution. **Error**, for errors or negative information. **Alternative**, similar to neutral but with a more subtle background. |
| Size | Size of the component. |
| Show button | Option to show a button within the component. The regular button is the **secondary** one — use the primary only if you need to draw extra attention. |
| Show asset | Option to show a graphic asset within the component. |
| Asset type | Choose among icon or emoji. |
