# Guidelines

<ComponentTabs basePath="/components/feedback/message-box" />

## Usage

Use the message box for important, persistent information about the user or their work — e.g.
account limits or status changes — that deserves more visual weight than a Snackbar or Message bar.

## Constraints

The prefix can be any icon or emoji, but its size variant can't be changed. The message box's
height adjusts dynamically based on whether a prefix, body, and button are shown. The button area
follows the same width constraints as the text area above it.
