# Content

<ComponentTabs basePath="/components/feedback/message-bar" />

- **Title**: state the ongoing status plainly — "Location Services Off," not a vague prompt.
- **Body** (expandable variant): only add detail that helps the user understand or resolve the
  status — keep it short even when expanded.
- **Link**: use a short, specific label for the action, like "Turn on" or "Learn more."
