## Component

<ComponentImage src="/img/components/message-bar/message-bar-overview.png" alt="Message bar types, prominence, and expandable variants" />

Message bars provide continuous information to the user — unlike a Snackbar, they don't
disappear on their own, and unlike a Message box, they're always anchored right below the
navigation bar rather than placed within the page's content.

## Properties

| Property | Details |
| --- | --- |
| Type | **Neutral**, **Success**, **Alert**, or **Error** — match the nature of the ongoing status. |
| Prominence | **Pale** or **Bold** — Bold draws more attention. |
| Expandable | **False**, or **True** (collapsed/expanded) — allows a longer message to be revealed on tap. |
| Link | (Optional) A text link, shown via `Show Link`. |
