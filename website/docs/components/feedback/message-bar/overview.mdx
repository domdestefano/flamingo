## Component

<ComponentImage src="/img/components/message-bar/message-bar-overview.png" alt="Message bar types, prominence, and expandable variants" />

A message bar is used when you want to inform continuously about an important information that
needs to be (ideally) resolved.

The content can be either about the state of the app, or of a specific screen:

| State of the app | State of specific screen (or part of the app) |
| --- | --- |
| The state affects the whole app (i.e. no internet) | The state affects the user or the app only in some specific parts of the app. |

The message bar disappears when the state that triggered it in the first place goes away (i.e.
internet was unavailable and is now back). If another state happens while the message bar is
already in place, the more recent one takes place. When it disappears, the previous one appears
back on.

### Message bar vs. Message box

The message bar is attached to the header and shows information continuously. This gives it more
visibility compared to a message box, which is placed in the content part of a page.

## Properties

| Property | Details |
| --- | --- |
| Type | **Neutral**, used for neutral or not very important information. **Alert**, used for information that should alert the user. **Error**, used for very important information that may lead to errors, dangerous actions, or states negatively impacting the user or the app. **Success**, used to briefly indicate a state change to a positive resolution. |
| Prominence | **Pale** or **Bold**. |
| Expandable | **False**: bar cannot be expanded. **True**: bar can be expanded and will show additional information. |
| Icon | Icon (on the left). |
| Title | String. |
| Description | String — only available when expanded. |
| Button | **No**: no button shown. **Yes**: button visible — only available when expanded. |
| Button label | String. |

:::info Usage of Success type
This state is only there to briefly indicate if a global App state changed from a negative (alert
or error) state to it being resolved (i.e. App had no internet connection to internet available
again).
:::
