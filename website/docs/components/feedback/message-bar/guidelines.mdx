# Guidelines

<ComponentTabs basePath="/components/feedback/message-bar" />

## Usage

Use the message bar for genuinely ongoing, important status information — e.g. location services
being off, or a persistent connectivity issue — not for one-off confirmations (use a Snackbar) or
promotional content.
