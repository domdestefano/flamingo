## Component

<ComponentImage src="/img/components/tag/tag-overview.png" alt="Tag prominence variants: pale and bold, with and without an icon" width={300} />

1. Pale - No icon
2. Pale - With icon
3. Bold - With icon

Tags are used to indicate the status of the rider or things related to them, like shifts, quests,
or orders — e.g. "New," "In progress," "Expired."

## Properties

| Property | Details |
| --- | --- |
| Type | **Success**, **Alert**, **Error**, **Neutral**, **White**, **Transparent**, or **Default** — match the status being communicated. |
| Prominence | **Pale** or **Bold** — Bold draws more attention, use for statuses that need to stand out. |
| Icon | (Optional) Shown or hidden via `Show Icon`. |

## Constraints

Tags should consist of a single word or a couple of words. The character count should not go
beyond 30 characters — it isn't meant to stretch to fit longer text.
