# Content

<ComponentTabs basePath="/components/buttons/automatic-button" />

We strongly suggest using a caption or label style above or below the automatic button to clarify
what action will be triggered, or what will happen once the countdown ends — the button label
alone often isn't enough context for a time-limited action.

## Truncation

The exact value of the remaining seconds can be hidden, showing only the countdown animation. In
that case, we strongly suggest using a caption or label style above or below the button to clarify
how many seconds are left, or how the timer/action behaves before it triggers.
