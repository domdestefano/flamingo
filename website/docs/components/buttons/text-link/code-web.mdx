# Code - Web

<ComponentTabs basePath="/components/buttons/text-link" />

## Preview

A text link isn't a standalone component — there's no Storybook story for it. It's applied by
styling a run of text with `color.primary.main` (active) / `color.primary.dark02` (pressed) inside
whichever text component already renders the surrounding copy.

## API

No API table — a text link has no props of its own; it's a text style applied to existing content.
