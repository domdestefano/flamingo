## Component

A text link **isn't a Figma component** — there's no reusable instance to place. It's applied
directly to a run of text within a text block, the same way a hyperlink works on the web. See
[How to apply a text link](/components/buttons/text-link/guidelines#how-to-apply-a-text-link) on
the Guidelines tab.

## Properties

| Property | Details |
| --- | --- |
| Size | The size of the link depends on the size of the text it's part of. |
| State | **Active**: the link is clickable. **Pressed**: the link is being pressed. |
