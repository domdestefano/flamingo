# Content

<ComponentTabs basePath="/components/buttons/text-link" />

A text link's label is whichever run of text it's applied to — there's no separate label field.
Keep the linked text short and specific about where it leads (e.g. "Privacy Policy", not "here" or
"click this").

## Truncation

Text links inherit the truncation behaviour of the surrounding text block they're part of — they
don't truncate independently. If the parent text wraps or truncates, the link wraps or truncates
along with it.
