2. Icon left and right

5. Loading
6. Inverted (for darker-coloured backgrounds)

Use the secondary button for **medium emphasis** — for the secondary action on a screen. This may
imply that there's also a primary and more important action on the screen. The secondary button is,
in general, used for actions that are somewhat important.

## Properties

| Property | Details |
| --- | --- |
| Size | Use according to the relevance of the action on the page — the same two sizes as the primary button. |
| State | **Active**: the button is clickable. **Pressed**: the button is being pressed. **Inactive**: the button is not interactive and not clickable. |
| Inverse | Use the inverse property only for darker-coloured backgrounds, e.g. an image or a dark section of the UI, so the button stays legible. |
| Icon | (Optional) Ability to add an icon left or right of the text. |

### Left or right icon

The use of the icon is used as a **visual assistance to the label**, in order to make the user
understand the action faster.

Generally, we recommend to **not use an icon in the secondary button if not explicitly needed**. If
you still decide to use one, consider the following:

- Think of its direction based on the action that you want the user to trigger or initiate. In
  western countries the human brain tends to read from left to right. Use the button with the left
  icon variant when you want to draw the user's attention to the icon first and then the label.
- You should use the button with left icon variant also when an action refers to a **flow going
  backward**, i.e. a step back would require putting the icon on the left hand side rather than on
  the right.
- In the opposite way, use the button with right icon variant when an action refers to a **flow
  going forward**, i.e. the next step would require putting the icon on the right hand side rather
  than on the left.

### Clickable area

The secondary button's background is intentionally low-opacity, which can make its visible bounds
look smaller than a primary button's. Its actual tappable area still meets the standard touch
target size — don't shrink the hit area to match the faint background visually.
