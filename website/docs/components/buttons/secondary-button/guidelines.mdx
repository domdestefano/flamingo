# Guidelines

## Usage

Use the secondary button for medium emphasis — a supporting action alongside (or instead of) a
primary button. It signals "this matters, but less than the primary action."

## Placement

1. The secondary button can be placed **anywhere, and several times, on the screen** — unlike the
   primary button, which is limited to one per screen.
2. It can be sticky if necessary, but doesn't have to be reachable by default the way a primary
   button does, since it's not the most important action — reachability here is by the user's
   choice, not a requirement.
3. The secondary button **cannot be placed inside a navigation bar** element.

### Caution: repetition

Avoid using several secondary buttons in a row for similar, repeated actions — at that point none of
them reads as more important than the others, which defeats the purpose of a "medium emphasis"
button. Consider a list or menu pattern instead.
