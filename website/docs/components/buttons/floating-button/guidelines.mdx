# Guidelines

<ComponentTabs basePath="/components/buttons/floating-button" />

## Usage

Use the floating button for the single most prominent action on a layered UI — most commonly a map
— where the action needs a text label to be unambiguous, unlike the icon-only floating icon button.

## Placement

1. The floating button is anchored to the **viewport, not the scrolling content** — it floats in a
   fixed position (typically bottom-right) above whatever is underneath.
2. It should always be **reachable**, since floating actions exist specifically to stay accessible
   while the rest of the screen scrolls or changes.
3. Don't place a floating button where it can permanently obscure content the user needs to read or
   interact with.
