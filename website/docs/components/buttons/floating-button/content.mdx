# Content

<ComponentTabs basePath="/components/buttons/floating-button" />

The floating button carries a short text label (plus an optional icon) — the same button text
rules as every other button apply: short, clear, **action + noun** phrasing, sentence case, no
"Click".

## Truncation

Multi-line buttons are not supported in Flamingo. Keep floating button labels especially short —
they have less horizontal room than a full-width Primary button, so truncation happens sooner.
