## Component

<ComponentImage src="/img/components/fab/fab-overview.png" alt="Floating button variants: default/prominent type, active/pressed/inactive/loading state" />

Use floating buttons for **prominent actions in a UI that consists of multiple layers on top of
each other**, like a map-based interface — e.g. "Start navigation" over a route preview. Unlike the
floating icon button, it always carries a text label, so use it when the action needs to be
unambiguous rather than universally recognisable from an icon alone.

A layered UI means the screen or flow consists of multiple layers that overlap on top of each
other — like a map-based screen, where the main action sheet overlaps the map layer, and actions on
top of the map need to "float" to ensure high contrast and hierarchy. The floating state also
shows that when the user interacts with the layer below, the actions keep their position.

## Properties

| Property | Details |
| --- | --- |
| Type | **Default**: a lighter-weight floating action. **Prominent**: a solid dark background, for the single most important floating action on screen. |
| State | **Active**: the button is clickable. **Pressed**: the button is being pressed. **Inactive**: the button is not interactive and not clickable. **Loading**: the button is showing that an action is being triggered. |

### Clickable area

The floating button's tappable area matches its visible background, but still meets the standard
touch target size regardless of where it's placed on screen.
