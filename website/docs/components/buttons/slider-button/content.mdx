# Content

<ComponentTabs basePath="/components/buttons/slider-button" />

The slider button's label should instruct the user on the gesture, not just the outcome — e.g.
"Slide to accept" rather than just "Accept". If a countdown timer is shown alongside the label,
keep the label short enough that both fit comfortably on the track.

## Truncation

Truncation behaviour hasn't been finalised in the source design spec yet — this component is
still marked "In progress". Check back once its guidance is complete.
