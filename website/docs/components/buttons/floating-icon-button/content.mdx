# Content

<ComponentTabs basePath="/components/buttons/floating-icon-button" />

The floating icon button has no text label by design — its icon must be immediately recognisable
without a caption, the same as a regular icon button.

## Accessibility

- Every floating icon button must have an accessible label (e.g. `aria-label` on web) describing
  the action it performs, since there's no visible text for assistive technology to read.
