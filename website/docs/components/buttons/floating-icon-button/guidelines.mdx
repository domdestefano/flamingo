# Guidelines

<ComponentTabs basePath="/components/buttons/floating-icon-button" />

## Usage

Use the floating icon button for subtle actions on top of a layered UI — most commonly a map —
where the action needs to stay accessible regardless of what's underneath it.

## Placement

1. Floating icon buttons are anchored to the **viewport, not the scrolling content** — they float
   in a fixed position (typically bottom-right) above whatever is underneath.
2. They should always be **reachable**, since floating actions exist specifically to stay
   accessible while the rest of the screen scrolls or changes.
3. Don't place a floating icon button where it can permanently obscure content the user needs to
   read or interact with.
