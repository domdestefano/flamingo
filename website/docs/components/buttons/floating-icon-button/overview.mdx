## Component

<ComponentImage src="/img/components/fab-icon/fab-icon-overview.png" alt="Floating icon button variants: default/destructive type, active/pressed/inactive/loading state" />

Use floating icon buttons for **subtle actions in a UI that consists of multiple layers on top of
each other**, like a map-based interface — e.g. recentring the map or toggling a layer.

## Properties

| Property | Details |
| --- | --- |
| Type | **Default**: the standard subtle floating action. **Prominent**: a solid dark background, for a floating icon action that needs more visual weight than Default. |
| Destructive | Use the destructive colour only for an action that removes or undoes something (e.g. stopping a live session). |
| State | **Active**: the button is clickable. **Pressed**: the button is being pressed. **Inactive**: the button is not interactive and not clickable. **Loading**: the button is showing that an action is being triggered. |
