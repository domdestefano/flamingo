# Tertiary button <StatusBadge status="stable" />

Indicate the last, least important, or most repetitive action on a screen.

## Component

<ComponentImage src="/img/components/tertiary-button/tertiary-button-overview.png" alt="Tertiary button states: active, pressed, inactive, loading, and icon left/right" />

1. Active, pressed, inactive, and loading states
2. Icon left and right

Use the tertiary button for **low emphasis** — for the last or least important actions on a screen.
It's also the right choice for **repetitive actions**, when icons alone can't clearly communicate
what the action does.

## Properties

| Property | Details |
| --- | --- |
| State | **Active**: the button is clickable. **Pressed**: the button is being pressed. **Inactive**: the button is not interactive and not clickable. **Loading**: the button is showing that an action is being triggered. |
| Icon | (Optional) Ability to add an icon left or right of the text. |

## Anatomy

<ComponentImage src="/img/components/tertiary-button/tertiary-button-anatomy.png" alt="Tertiary button anatomy: icon and text" />

1. Icon
2. Text

Unlike Primary and Secondary button, the tertiary button has no background — it's text (plus an
optional icon), styled to read as clickable without competing visually with higher-emphasis
actions on the same screen.

### Clickable area

The tertiary button's tappable area is larger than its visible text, so it still meets the
standard touch target size even though the label itself is small — don't shrink the hit area to
match the text visually.
