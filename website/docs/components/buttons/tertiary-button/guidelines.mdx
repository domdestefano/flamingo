# Guidelines

<ComponentTabs basePath="/components/buttons/tertiary-button" />

## Usage

Use the tertiary button for low emphasis — the last or least important action on a screen, or for
repetitive actions that would be too visually heavy as a Secondary button repeated many times.

## Placement

1. The tertiary button can be placed **anywhere, and several times, on the screen** — like the
   secondary button, it isn't limited to one per screen.
2. It doesn't need to be reachable by default — being the lowest-emphasis action, there's no
   expectation the user needs it immediately.
3. The tertiary button **cannot be placed inside a navigation bar** element.
