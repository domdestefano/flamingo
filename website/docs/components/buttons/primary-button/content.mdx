# Content

<ComponentTabs basePath="/components/buttons/primary-button" />

Buttons use short, clear text that communicates what the user can expect from interacting with that
button. Buttons use as few words as possible and do not offer conflicting or repetitive text. In
most cases, the text in a button uses only an **action + noun** format. There is a rare exception
made for using an action only for clear navigations like "Next" or "Back", but these should be used
when the context is clear as to the behaviour of that button. Button text uses user-friendly terms.
Buttons never use the word "Click". Avoid using abbreviations or acronyms in a button label, unless
they are commonly understood by the target audience. Avoid using multiple words in a button label,
as this can make it difficult to tap accurately with a finger.

## Appearance

- Text is always sentence case and centre-aligned within the button.
- When an icon is used, it becomes part of the text block that is centred in the container. Use
  appropriate iconography to supplement button labels, if necessary. In the status "Loading" and
  variant "Automatic", the same behaviour applies to the loading spinner as well.

## Truncation

Truncation behaviour refers to how text is displayed on buttons in mobile interfaces when it is too
long to fit within the button's dimensions. Multi-line buttons are not supported in Flamingo.

Guidelines on truncation behaviour of buttons in mobile interfaces:

- **Use truncation when necessary**: if the text on a button is too long to fit within the button's
  dimensions, it should be truncated to prevent the button from appearing cluttered.
- **Use ellipsis to indicate truncation**: when truncating text on a button, use an ellipsis (…) at
  the end of the truncated text to indicate that the text has been truncated.
- **Avoid truncating important words**: when truncating text on a button, avoid truncating important
  words or phrases that may affect the button's meaning or functionality.
- **Use appropriate truncation length**: when truncating text on a button, choose a truncation length
  that is appropriate for the button's dimensions and the amount of text being truncated.
- **Test truncation behaviour**: before implementing truncation behaviour on buttons in a mobile
  interface, test it to ensure that it is effective and intuitive for users.
