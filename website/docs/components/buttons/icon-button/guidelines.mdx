# Guidelines

<ComponentTabs basePath="/components/buttons/icon-button" />

## Usage

Use the icon button for minimal-emphasis, icon-only actions — things like closing a sheet, opening
a menu, or a header action that's common enough not to need a text label.

## Placement

1. The icon button can be placed **anywhere, and several times, on the screen** — most commonly in
   headers, list rows, and toolbars.
2. It doesn't need to be reachable by default — being the lowest-emphasis, icon-only option, there's
   no expectation the user needs it immediately.
3. The icon button **cannot be placed inside a navigation bar** element as a replacement for the
   nav bar's own dedicated action slots.
