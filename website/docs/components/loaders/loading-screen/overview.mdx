## Component

Screen states are full screen states that appear when the UI is in a temporary state before
showing the actual content intended for the user to be consumed or interacted with — e.g. a
loading screen when arriving at the vendor and the app is loading the new vendor pick-up flows.

Screen states need to be particularly clear for the user, as they are not regular screens the
user consumes but, instead, bridge the gap between steps in a flow or different flows together.

Note this is distinct from the [Skeleton screen](/components/loaders/skeleton-screen/overview)
component — the Loading screen is a full-screen scrim + spinner + title state shown before any
layout is known, while the Skeleton screen previews the upcoming layout with placeholder shapes.
