# Guidelines

<ComponentTabs basePath="/components/loaders/skeleton-screen" />

## Usage

Use a skeleton screen for a full page or section's first load, when there's no content at all yet
to show progressively — arrange skeleton shapes to roughly match the layout that's about to
appear, so the transition to real content feels continuous rather than jarring.

This repo's Figma spec doesn't yet include distinct Do/Don't usage examples for the full-screen
composition (only the underlying [Skeleton](/components/loaders/skeleton/overview) component has them) — if
those get added, register their frames and add a Use cases section here following the pattern used
elsewhere.
