## Component

<ComponentImage src="/img/components/skeleton-screen/skeleton-screen-overview.png" alt="A full skeleton screen made of stacked skeleton bars" width={300} />

The Skeleton screen is a standardized component designed to streamline the process of
speccing/implementing full-page skeleton loaders.

- The layout does not match any one page in the app exactly, but is generic enough to work for
  all use cases.
- Avoid using custom/one-off skeleton screens, as they're disconnected from Flamingo and require
  manual upkeep.

This isn't a separate coded component — it's a composition pattern: repeat and arrange
[Skeleton](/components/loaders/skeleton/overview) shapes to preview the layout of the screen that's about
to load, then swap them for the real content once it's ready.

Note this is distinct from the [Loading screen](/components/loaders/loading-screen/overview)
component — the Skeleton screen previews the upcoming layout with placeholder shapes, while the
Loading screen is a full-screen scrim + spinner + title state shown before any layout is known.
