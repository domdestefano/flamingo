## Component

<ComponentImage src="/img/components/skeleton/skeleton-overview.png" alt="Skeleton shapes: square and bar, big/medium/small" />

Skeletons are a loading element that help the user predict what to expect when the real UI
displays.

- In most cases, **designers should not use these individual Skeleton components** — instead use
  the [Skeleton screen](/components/loaders/skeleton-screen/overview) component.
- Custom skeleton arrangements should be used only if absolutely necessary. **Consult with the
  Flamingo design team before attempting this solution.**

## Properties

The component has several properties, you can choose from:

| Property | Details |
| --- | --- |
| Size | The skeleton comes in **3 sizes**, depending on the prominence the real UI that designers are trying to approximate. For instance, a line of loading body text is represented by `skeleton.small.bar`. |
| Shape | **Square**: the skeleton has equal width + height (the updated design renders it circle-shaped). **Bar**: the bar has a set height based on the size, but the width is configurable. |
| Type (⚠️ Deprecate) | We currently have "Light" and "Dark" variants of skeletons (for use on white and grey backgrounds respectively), but this is no longer needed because we updated to transparent fill colours. Only use the **"light"** variant in your designs ("dark" will be marked as deprecated in Figma). |

### Size and shape

Skeletons are available in 2 shapes and 3 sizes.

- "Square" shape is used to represent images and icons.
- "Bar" shape is used to represent lines of text or buttons.
- Big/medium/small sizes allow flexibility to match page hierarchy.
