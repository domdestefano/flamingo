## Component

<ComponentImage src="/img/components/skeleton/skeleton-overview.png" alt="Skeleton shapes: square, bar, and circle, in light and dark, big/medium/small" />

Skeleton components are UI elements used to provide a visual hint of the content that is loading.
After loading completes, skeletons are replaced with the actual UI elements of the screen.

## Properties

| Property | Details |
| --- | --- |
| Shape | **Square**, **Bar**, or **Circle** — match the shape of the real content this skeleton stands in for (e.g. Circle for an avatar). |
| Size | **Big**, **Medium**, or **Small** — match the size of the real content. |
| Type | **Light** or **Dark** — match the surface it sits on. |
