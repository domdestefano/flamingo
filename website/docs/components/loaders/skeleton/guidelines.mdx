# Guidelines

<ComponentTabs basePath="/components/loaders/skeleton" />

## Usage

Use skeletons to represent content that's actively loading, arranged to roughly match the layout
of the real content that will replace them — this sets the right expectation for what's coming and
reduces perceived wait time.
