## Interactions

### Forward loading

The loading bar **increases** in length, according to the time of the loading that's taking
place.

### Backward loading

The loading bar **decreases** in length, according to the time of the loading that's taking
place.

## Placement

If they sit:

- **At the top of the screen**, they should be right below the header, and they indicate the
  loading of all the screen content or the fetching of new data.
- **Attached to a container**, such as a card or a bottom sheet, they indicate that the loading
  process applies to that particular item (and that interaction with the rest of the UI is
  possible).

## Do's and Dont's

### Loading bars in buttons

Do not place loading bars within buttons, to indicate the loading of the action triggered by the
buttons. For these cases, use the loading button or automatic button instead. The loading variant
shows an indeterminate loading spinner inside the button itself, while the automatic button uses
the countdown to let the user perform an action before the countdown is over.
