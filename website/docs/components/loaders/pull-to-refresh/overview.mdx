## Component

The pull-to-refresh or swipe-to-refresh UI element lets a user pull down on a list of data being
viewed in order to retrieve more data or refresh the UI. The refresh indicator uses **only in
conjunction with a refresh gesture** or action.

Pull to refresh works well for lists and card collections where content is updated frequently, or
when the collection usually requires a constantly-updating stream of items — the pull to refresh
gives the user the impression that new content will always appear when refreshing the UI. It's a
safety mechanism because even if the loading of new content fails, the user can pull to refresh to
restart the loading process.

Appropriate use cases for pull-to-refresh are:

- Content feeds
- Inbox messages

## Pull to refresh vs. loading bar

Pull to refresh uses a manual gesture triggered by the user to force the loading of new and
updated content. Loading bars, instead, are used when the loading is triggered by an action
performed by the system (not the user), for content different from a manual gesture.
