# Component gallery apps

View our implemented components and test how they behave.

<UpdateBanner date="Oct 2025" />

Gallery Apps (or pages) show the implemented Flamingo components. They show all
options available on the live components.

They are available for all platforms:

| Web | iOS & Android |
| --- | --- |
| Current library (we will deprecate this, once the new library is finished and all teams migrated to it)<br/>New library | Android<br/>iOS |

## How to test Native (iOS/Android) gallery Apps

Native Gallery Apps can be downloaded on real devices. Alternatively, we
recommend using a tool called **Lambda Test**. It simulates devices on your
web browser — ask the team for access.

You can ask the engineers for the APK, or build it yourself from source.
