## Component

<ComponentImage src="/img/components/text-input/text-input-overview.png" alt="Text input with title, leading icon, prefix, suffix, and trailing icon" />

Text inputs allow users to enter shorter text into a UI. These are UI elements that are used by
the user to type in pieces of textual information, e.g. the user's email address. They can be
shown in different formats, depending on the information requested — for example a phone number
has a different format than a credit card number.

### Text input vs. Text area

The text input is used for single-line text input purposes, meaning that the user should be able
to only type a word or a very short sentence (e.g. their name or password). If more text is
needed, use the [text area](/components/form/text-area/overview) instead, as it has more space to
allow the user to type multi-line sentences.

## Properties

| Property | Details |
| --- | --- |
| State | **Empty**: user has not entered any information yet and sees a placeholder. **Filled**: a text was typed in. These two categories apply to the following states — **Default**: text field hasn't been tapped on by the user/text input is resting. **Focused**: user has tapped on the text input and it is in focus. **Inactive**: the text field is unavailable to the user to tap in — it cannot be edited at the moment or locked. **Error**: an error occurred and we need to visually draw the user's attention to fix the error — without fixing it, it cannot be completed. |
| Text (Placeholder or Input) | The text which the user has to fill in. |
| Header | (Optional) Description. |
| Title | (Optional) Part of the header — describes what the field is about. |
| Required Label | (Optional) Part of the header — represents that the input it refers to needs to be filled out in order to advance or complete a flow. |
| Hint text | (Optional) Represents a helper text to explain further what is requested from the user. |
| Error text | (Recommended for error state) represents the text to explain the error that occurred when validating the text — e.g. the used password is too short. |
| Icon | (Optional) Visual assistant to the text input — e.g. a mail icon for the email text input. |
| Affix / Prefix | (Optional) Text elements used as visual assistants to the text input — e.g. the °C to indicate the degree format the user has to put the temperature in. |
| Icon button | (Optional) Used to display actions within the text input — e.g. a show/hide icon to show or hide the password characters, or a calendar icon for date inputs. |
