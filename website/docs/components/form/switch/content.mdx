# Content

<ComponentTabs basePath="/components/form/switch" />

- Phrase the label as the state being enabled, not a question — "Enable dark mode," not "Do you want dark mode?"
- Keep the label to one short line where possible (max 2 lines).
- If the setting's effect isn't obvious, add a short body text explaining it.
