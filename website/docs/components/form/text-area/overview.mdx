Lets the user enter longer, multi-line text.

## Component

<ComponentImage src="/img/components/text-area/text-area-overview.png" alt="Text area with title and multi-line input box" />

Styling (text colours, strokes, etc.) is the same as the Text Field.

## Properties

| Property | Details |
| --- | --- |
| State | Active / Inactive / Error. |
| Show Header | Optional — toggles the Field title row. |
| Show Required label | Optional — toggles the "Required" label. |
| Show Hint | Optional — toggles hint text below the field. |
| Show Error message | Optional — toggles an error message below the field. |
