# Guidelines

<ComponentTabs basePath="/components/form/text-area" />

## Placement

To make sure users have enough space to see the whole content of the text area, try to avoid
placing it on cards.

## Use cases

### Text input vs. Text area

Use text areas for longer text inputs.

<DoDontTable
  doImage="/img/components/text-area/text-area-fieldtype-do.png"
  doText="Users should be able to see most of their text, when the input will be longer."
  dontImage="/img/components/text-area/text-area-fieldtype-dont.png"
  dontText="Avoid using text areas for short inputs."
/>

### Added information

Be specific when adding hints, placeholders, and titles. They should help the user fill in the
field.

<DoDontTable
  doImage="/img/components/text-area/text-area-amount-do.png"
  doText="Explain clearly what the user should fill in."
  dontImage="/img/components/text-area/text-area-amount-dont.png"
  dontText="Don't let the user guess what they need to fill in."
/>
