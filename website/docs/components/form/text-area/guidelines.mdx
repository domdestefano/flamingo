# Guidelines

<ComponentTabs basePath="/components/form/text-area" />

## Usage

Use a Text Area for longer, multi-line input — a comment, a description, feedback. Don't use a
Text Area for a short single value like a name or amount; use a Text Field instead.

## Use cases

Figma's spec includes "Field type" and "Amount of Information" Do/Dont scenarios, but both use
identical placeholder content with no visible distinction between the Do and Don't frames — so no
example is included here rather than guessing at what the distinction was meant to show.
