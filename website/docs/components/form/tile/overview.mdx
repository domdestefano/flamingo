## Component

<ComponentImage src="/img/components/tile/tile-overview.png" alt="Tile with icon and label" />

Tiles are UI elements that help people make selections across different options. They are
interactive, meaning that they can be tapped and the selection state changes from selected to
unselected and vice-versa.

- Tiles are always grouped together (min. 2) in a tile group.
- Tile groups can be displayed horizontally or vertically.
- Based on the use case you can apply the logic of selecting multiple tiles at once, or select
  only one at a time. Changing the choice in a single-choice setup will deselect the other tile.

### Tiles vs. checkbox/radio button vs. chips

The main difference between a tile and a chip or checkbox/radio button is the prominence you want
to give the items to select. Chips are more subtle and smaller in size, meaning that you can
display more at once but can also be overlooked or skipped through.

Use tiles when you don't want the users to miss on certain options, or when you want to add
visual support to a selection.

## Properties

| Property | Details |
| --- | --- |
| State | **Active**: indicating that the tile can be tapped on/interacted with. **Selected**: indicating that the tile has been selected. **Inactive**: indicating that the tile cannot be selected or interacted with. |
| Icon | Icon type that is being displayed on the tile. |
