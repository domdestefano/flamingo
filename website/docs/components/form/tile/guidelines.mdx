# Guidelines

<ComponentTabs basePath="/components/form/tile" />

## Usage

Use Tiles for a small set of visually distinct options the user picks from — each tile pairs an
icon with a short label. Don't use Tiles for a long list of options; use a different selection
pattern instead.
