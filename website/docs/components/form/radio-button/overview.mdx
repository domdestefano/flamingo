# Radio Button <StatusBadge status="stable" />

Lets the user make one choice among several mutually-exclusive options.

## Component

<ComponentImage src="/img/components/radio-button/radio-button-overview.png" alt="Radio button, selected state" />

For a radio button used alongside text, use the Simple list item and set its prefix to "radio
button" rather than composing one from scratch.

## Properties

| Property | Details |
| --- | --- |
| Active | Whether the radio button is enabled/interactive. |
| Selected | Whether this option is the one chosen in the group. |
