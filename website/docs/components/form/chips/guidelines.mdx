# Guidelines

<ComponentTabs basePath="/components/form/chips" />

## Usage

Use chips for filtering or lightweight selection — single-select for one active filter at a time,
multi-select for any combination, and removable chips for tokens the user added themselves (e.g.
applied filters) that they can individually clear.
