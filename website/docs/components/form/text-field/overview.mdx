## Properties

| Property | Details |
| --- | --- |
| State | Active / Inactive / Error. |
| Show Header | Optional — toggles the Field title row. |
| Show Required label | Optional — toggles the "Required" label. |
| Show left Icon | Optional — toggles a leading icon. |
| Show Prefix | Optional — toggles a prefix label (e.g. a currency symbol). |
| Show Suffix | Optional — toggles a suffix label (e.g. a unit). |
| Show Icon button | Optional — toggles a trailing icon button. |
| Show Hint | Optional — toggles hint text below the field. |
| Show Error message | Optional — toggles an error message below the field. |
