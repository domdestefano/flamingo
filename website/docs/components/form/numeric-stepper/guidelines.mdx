# Guidelines

<ComponentTabs basePath="/components/form/numeric-stepper" />

## Placement

Place the numeric stepper close to the label or content it modifies — a quantity, a count, a
rating — so the relationship between the value and what it represents is unambiguous. Give it
enough surrounding context (a title, an icon, a unit) that the number alone isn't left to speak
for itself.

## Min/Max behaviour

  doImage="/img/components/numeric-stepper/numeric-stepper-minmax-do.png"

## Range size

<DoDontTable
  doImage="/img/components/numeric-stepper/numeric-stepper-range-do.png"
  doText="Use a numeric stepper for small, precise adjustments where every tap has clear meaning — quantity pickers, small counters, ratings."
  dontImage="/img/components/numeric-stepper/numeric-stepper-range-dont.png"
  dontText="Don't use a bare stepper for a very wide range (e.g. 0–1000) with no faster way to reach a distant value — pair it with a direct editable field instead."
