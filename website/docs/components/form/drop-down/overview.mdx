## Component

<ComponentImage src="/img/components/drop-down/drop-down-overview.png" alt="Drop down with title and selected item" />

1. DD with all of its options
2. Resting
3. Drop down which is currently open (the screen shows a bottom sheet with a selector)
4. Inactive state

Note: in Storybook and code, this component is named **Dropdown** (one word). Styling (text
colours, strokes, etc.) is the same as the Text Field.

## Properties

| Property | Details |
| --- | --- |
| State | Active / Selected / Inactive. |
| Show Header | Optional — toggles the Field title row. |
| Show Required label | Optional — toggles the "Required" label. |
