# Guidelines

<ComponentTabs basePath="/components/form/drop-down" />

## Usage

Use a Drop Down to let the user pick one option from a list, when showing every option at once
(e.g. as radio buttons) would take up too much space. Don't use a Drop Down for a binary choice;
use a Switch or Checkbox instead.

## Use cases

Figma's spec defines three named Usage scenarios — Titles, Categories, and Multiple Choices — but
every Do/Dont/Caution frame in all three uses identical placeholder content with no visible
distinction between them. No example images are included here rather than guessing at what each
scenario was meant to show.
