# Icons <StatusBadge status="stable" />

Small graphic elements to accompany other UI elements

<ComponentTabs basePath="/components/assets/icons" />

## Usage

Use icons when you want to support information with a graphical element; for
this reason, icons should be extremely clear on what they mean.

## Placement

1. **On the screen**: The icon can be placed anywhere in the screen.
2. **Within components or compositions**: Icons are usually placed as
   prefixes, on the left side or top part of the component or composition.
   They can be placed below main elements for appropriate hierarchy.
3. Icons should not be used alone, as they are non-interactive elements, but
   always grouped with other elements, like text or components.

## Use Cases

### Sizes

Icons sizes should be used harmoniously with the elements they accompany, and
according to the prominence you want to convey.

<DoDontTable
  doText="Choose the icon size based on the element it accompanies"

### Clear iconography

Make sure to use very clear icons, in order to convey simple messages.

<DoDontTable
  doText="Simple icons are easier to understand"
  dontText="Icons that are repetitive for different meanings or unclear can lead to confusion"
/>

### Hardcoded colours

Make sure to use Flamingo's colour tokens, so that they change accordingly to
the theme of each brand and to Dark mode settings.

<DoDontTable
  doText="Correct colour tokens work harmoniously with each other"
  dontText="Hardcoded HEX values might not translate well in other settings, like Dark mode"
/>
