## Component

<ComponentImage src="/img/components/icons/icons-overview.png" alt="Icon sizes: XL, L, Default, S, and XS, each with active and inactive states" />

There are 5 sizes for icons: XL, L, Default, S, and XS — each with active and
inactive states.

Icon assets are the UI element you should use whenever you want to add a
non-interactive icon to your interfaces.

- There are 5 sizes for the icons.
- Icons have an active and inactive state.
- The icon UI element has an instance connected to the icon library. This
  means that the library is inside every icon UI element. In Figma, you can
  choose from the library by selecting the right icon from the menu on the
  instance property.
- If you need to use interactive icons, these are in icon buttons as they
  trigger interactions.

## Properties

The Icon component has two properties you can choose from:

| Property | Details |
| --- | --- |
| Size | Size of the container which scales up or down the pictogram inside. |
| Active or Inactive | **Active** is used by default. **Inactive** when the icon is used together with other inactive elements. |
| Icon | Menu to select the pictogram from our asset library. |

### Clickable area

The icon component is not clickable. For interactive icons, make sure to use
the Icon button.
