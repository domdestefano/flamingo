# Graphic blocks <StatusBadge status="stable" />

Complex and delightful graphic elements to accompany other UI elements

<ComponentTabs basePath="/components/assets/graphic-blocks" />

## Usage

Use the illustrations when you want to support information with a graphical
and delightful element, in a non crowded interface; for this reason,
illustrations should be extremely clear on what they mean. If your interface
has a lot of elements, we recommend using icons, which occupy less space.

## Placement

1. **On the screen**: The illustrations can be placed anywhere in the screen.
2. **Within components or compositions**: Illustrations can placed as
   prefixes or suffixes, on the left or right side or top part of the
   component or composition.
3. Illustrations should not be used alone, as they are non-interactive
   elements, but always grouped with other elements, like text or
   components.

## Use Cases

### Sizes

Illustration sizes should be used harmoniously with the elements they
accompany, and according to the prominence you want to convey.

### Clear iconography

Make sure to use clear illustrations, that refer clearly to the message you
want to convey.

Make sure to use Flamingo's colour tokens, so that they change accordingly to
the theme of each brand and to Dark mode settings.
