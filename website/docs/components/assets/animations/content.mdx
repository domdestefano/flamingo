## Purpose: The "Emotional Hook"

Delightful animations are about brand personality and user retention. They
transform a sterile transaction into a memorable experience.

- **Celebrate the "Win":** Use motion to reward a user for finishing a
  difficult task (e.g., a completing an order).
- **Ease the Wait:** Turn a boring loading state into an "Easter Egg." A
  clever, looping animation makes a 3-second wait feel like 1 second.
- **Surprise and Discovery:** Add subtle "micro-rewards" to hidden areas.

## Frequency & The "Annoyance Threshold"

A joke is only funny the first few times. Delightful animations must be
balanced so they don't become tedious.

- **The Rare Reward:** The more "extra" an animation is, the less often it
  should appear. Save the big fireworks for big moments (e.g., first order,
  not every page load).
- **Subtlety is King:** A tiny, 10° tilt of an icon when hovered is often
  more delightful than a full 360° spin.
- **Speed is Still Key:** Even "delightful" animations should be snappy. If a
  user is forced to watch a 2-second "celebration" before they can click the
  next button, the delight turns into frustration.
