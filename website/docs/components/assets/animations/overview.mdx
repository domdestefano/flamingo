## Component

<ComponentImage src="/img/components/animations/animations-overview.png" alt="Animation sizes recommended, unique sizing allowed in specific cases" />

There are 3 sizes for the animations we recommend, but in specific cases we
allow unique sizing.

Animations are UI elements you should use whenever you want to add a
delightful visual cue to your interfaces.

- There are 3 sizes for the animations we recommend, but in specific cases we
  allow unique sizing.
- Animations colours should change based on the brand (Not in Figma, due to
  limitations).
- The Animation UI element has an instance connected to the animations
  library. This means that the library is inside every Animation component.
  In Figma, you can choose from the library by selecting the animation from
  the menu on the instance property.

## Properties

The Animation has two properties you can choose from:

| Property | Details |
| --- | --- |
| Size | Size of the container which scales up or down the pictogram inside. |
| Animation | Menu to select the pictogram from our asset library. |

## Non branded animations

These elements do not change their colour based on the brand, and can refer
to:

- Neutral assets that don't need to be customised based on the brand, e.g.
  _Face recognition_ etc.

These are stored in the GitHub repository for non-branded assets, while in
Figma they are usually stored locally.
