# Guidelines

<ComponentTabs basePath="/components/navigation/header" />

## Usage

Use the Header at the top of every screen. Match its leading action to the screen's place in the
navigation hierarchy — a Hamburger menu (or no leading action) on entry-level pages, a Back button
on any page reached by navigating forward.
