# Content

<ComponentTabs basePath="/components/navigation/header" />

- Keep the title to one or two words wherever possible — it must fit on one line without truncating.
- Use sentence case for titles and subtitles.
- The subtitle should add context the title doesn't already cover — don't restate the title.
