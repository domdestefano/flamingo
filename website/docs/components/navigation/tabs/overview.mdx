## Component

<ComponentImage src="/img/components/tabs/tabs-overview.png" alt="Tabs, selected and unselected" />

Sticky tabs should contain content that is genuinely distinct from other tabs in the same set —
each tab represents a different view of the same screen, not a separate flow.

## Properties

| Property | Details |
| --- | --- |
| # of Tabs | The number of tabs in the set. |
| Selected Tab | Which tab is currently active. |
| Icon | (Optional) Shown or hidden per tab. |

## Anatomy

Each tab item has two states:

- **Selected** — filled background, indicating the currently active section.
- **Unselected** — a lighter, unfilled background.
