# Tabs <LastUpdatedBadge />

Tabs are used to create internal navigation within a screen. Depending on their usage, they can
switch the content of one section or an entire page.

## Component

<ComponentImage src="/img/components/tabs/tabs-overview.png" alt="Tabs, selected and unselected" />

- Tabs are used for all cases of internal page navigation.
- Use tabs in a sticky header if you want to switch the content of the entire scrolling area.
- Use tabs in the scrolling area if you want to switch the content of only one section.
- Add up to 6 tabs.

## Properties

| Property | Details |
| --- | --- |
| Number of tabs | 2 tabs / 3 tabs / 4 tabs / 5 tabs / 6 tabs. |
| Selected tab | 1st tab / 2nd tab / 3rd tab / 4th tab / 5th tab / 6th tab. |
| Icon | (Optional) Shown or hidden per tab. |
| Fill/hug | Whether tabs stretch to fill the available width or hug their own label. |
