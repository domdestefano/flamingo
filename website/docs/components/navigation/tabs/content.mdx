# Content

<ComponentTabs basePath="/components/navigation/tabs" />

- Keep each tab label to a word or two — long labels get truncated (see Guidelines).
- Use parallel phrasing across all tabs in a set — e.g. "Daily / Weekly / Monthly," not a mix of
  nouns and verbs.
