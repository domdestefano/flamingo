# Guidelines

<ComponentTabs basePath="/components/navigation/tabs" />

## Usage

Use tabs to switch between distinct views of the same screen — e.g. "Daily / Weekly / Monthly."
Don't use tabs for a multi-step flow; use a different navigation pattern for that.
