# Guidelines

<ComponentTabs basePath="/components/navigation/tabs" />

## Usage

- Use tabs for navigating to different pages or sections within a page.
- Place tabs in the sticky header if switching tabs changes the entire scrolling area.
- Place tabs in the scrolling area if switching tabs changes only one section of content.
- Don't display tabs if there is only one to show.
- Don't use tabs for any other type of selection/interaction (strictly for navigation).

## Placement

Tabs can be placed as a "stack" in the header component (to change the entire scrolling area), or
within the scrolling area (to change one section of content).

## Interactions

### Clickable area

The whole pill-shaped tab is the clickable area for unselected tabs, not just the label text.

### Scrolling area

Tabs are non-scrollable when the tab bar is narrower than the maximum width. If the tab bar's
content is wider than the screen, the whole tab bar becomes horizontally scrollable.
