# Content

<ComponentTabs basePath="/components/navigation/content-header" />

- Keep titles short and specific to the section — avoid generic labels like "Info" or "Details."
- Use sentence case for titles and descriptions.
- The description should add context the title alone doesn't cover — don't restate the title.
