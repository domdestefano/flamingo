# Guidelines

<ComponentTabs basePath="/components/navigation/content-header" />

## Usage

Use a Content header at the start of every distinct section of a page — Page, Section, or Subsection
level — to establish a clear hierarchy. Don't skip levels or use headers decoratively where no new
section actually begins.
