## Component

<ComponentImage src="/img/components/content-header/content-header-overview.png" alt="Content header with Title, Description, and content below it" />

Use the Content header to divide your page content into sections. This will guide users through the
interface and create structure.

## Properties

| Property | Details |
| --- | --- |
| Level | Page / Section / Subsection — sets the hierarchy the header represents. |
| Alignment | Default (left-aligned) / Centred. |
| Type | Default / Illustration-Animation. |
| Show description | Optional — toggles the description line. |
| Show action | Optional — toggles the trailing action (e.g. a tertiary button). |

## Anatomy

<ComponentImage src="/img/components/content-header/content-header-anatomy.png" alt="Content header anatomy: Title, Description, Action" />

1. **Title** — the section's name.
2. **Description** — optional supporting text.
3. **Action** — optional trailing control, e.g. a tertiary button.
