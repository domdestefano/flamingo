## Component

<ComponentImage src="/img/components/content-header/content-header-overview.png" alt="Content header with Title, Description, and content below it" />

Use the Content header to divide your page content into sections. This will guide users through the
interface and create structure.

The component can be used on three levels:

1. **Page header** — used to show the page name, a greeting, overview, or most relevant information.
2. **Section header** — used to name a section of a page.
3. **Subsection header** — used to name a subsection of a page.

## Properties

| Property | Details |
| --- | --- |
| Level | **Page**: used to display the page name. **Page/Section**: used to display the page or section name. **Subsection**: used to display a subsection — this should only be used if a Page or Section header was also used on the same page. |
| Alignment | **Default**: content is aligned LTR or RTL depending on the interface direction. **Centred**. |
| Type | **Empty**: nothing is displayed on the right-hand side. **Action**: displays a button or chevron on the right-hand side. **Illustration/Animation**: displays an illustration or animation on the right-hand side. |
| Action | If Type = Action, choose from: **None** (no action), **Chevron**, **Text button**, **Icon button**. |
| Title | The title of the section/page. |
| Description (optional) | Description of the section/page. |

## Anatomy

<ComponentImage src="/img/components/content-header/content-header-anatomy.png" alt="Content header anatomy: Title, Description, and an optional trailing button" />

1. **Title** — the section's name.
2. **Description** — optional supporting text.
3. **Button or asset** — optional, e.g. a tertiary button, chevron, icon button, or illustration/animation.

## Interactions

**Non-clickable** — when the component has no action, nothing is clickable.

**With chevron** — when the component displays a chevron, the whole component is clickable.

**With a button** — when the component displays a tertiary button or icon button, that control is
the clickable element rather than the whole header.
