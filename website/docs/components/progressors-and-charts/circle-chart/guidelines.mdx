# Guidelines

<ComponentTabs basePath="/components/progressors-and-charts/circle-chart" />

## Placement

- The component can be placed on the background, on cards, overlays or bottom sheets.
- Ensure there is enough space.

## Use cases

### Location

The Circle Chart is a highly visual component. Ensure it has enough space.

<ComponentImage src="/img/components/circle-chart/circle-chart-placement-do.png" alt="Circle chart placed left aligned with enough white space" />

Place it left aligned or when possible centred.

<CautionTable
  image="/img/components/circle-chart/circle-chart-placement-caution.png"
  text={<>When placing it beside another element, ensure there is still enough white space.</>}
/>

## Do's and Dont's

### Content

Ensure the type of the chart matches the message (see the Overview tab) and the content explains
what the chart is displaying.

<DoDontTable
  doText="The upper label explains what the bar is about and the lower one shows the actual value."
  dontText="Avoid ambiguous language — show exact values instead of vague ones. Also, don't display the chart without any context."
/>

## Interactions

### On load

On screen load, the bar of the Circle Chart progresses linearly from 0% to X% (X being the amount
of the Circle). These are the interaction properties for the progression:

| Property | Value |
| --- | --- |
| Easing function | `easingFunction01` |
| Duration | `duration06` |
