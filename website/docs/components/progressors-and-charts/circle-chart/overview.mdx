## Description

The Circle Chart is used to indicate a value in a more visual way. Circle Charts are for showing
**parts of a whole** or **progress toward a goal**, when that "whole" is clearly defined and
limited. The progression is continuous, meaning that it's not sectioned in fractions.

### Circle vs. Pie

The main difference is that the progression is continuous in the circle, while it's sectioned in
fractions in the pie. We recommend using the circle when the progression happens indeterminately
in a continuous way; use the pie when the progression is predefined in a series of steps that the
user has to go through in order to achieve completion.

### Circle vs. Progress Bar

Circle Chart and Progress Bar serve different mental models and UX contexts.

| Criterion | Circle Chart | Progress Bar |
| --- | --- | --- |
| Core purpose | Visualizes progress toward a goal or portion of a whole in a compact, symbolic way | Shows linear progression along a defined path or process |
| Mental model | Feels cyclical, looped, or holistic — completion "closes the circle" | Feels sequential or directional — progress "moves forward" |
| Use when... | You want to show progress as a single, self-contained metric (e.g. Battery 80%); you're comparing few, independent progress values | You need precise readability and users care about the actual numeric progress; you want to provide more context through labels |

## Properties

| Property | Details |
| --- | --- |
| Type | Default / Branded / Success / Alert / Error / Neutral — color of the ring. Default is generic progression with no positive/negative feeling; Branded is an alternative to Default; Success shows a positive completion feeling; Alert signals a possible stall; Error shows negative progress; Neutral is the inactive or locked state of the progression. |
| Secondary label | String explaining what the main label shows. |
| Main label | String showing the bar's value. |
| Progression | Value — how much progress the bar should display. |
