# Guidelines

<ComponentTabs basePath="/components/progressors-and-charts/pie-chart" />

## Usage

Use the pie chart when progress is naturally counted in discrete steps (e.g. "6 of 7 tasks done"),
not a continuous percentage — use the Circle Chart for that instead.
