## Component

<ComponentImage src="/img/components/pie-chart/pie-chart-overview.png" alt="Pie chart showing a fraction and discrete progress segments" />

The Pie Chart is used to indicate a fraction of something, i.e. the progress on a goal or activity. The user has to go through a series of stops in order to achieve completion.

## Pie vs. Circle

The main difference is that the progression is continuous in the circle, while it's sectioned in fractions in the pie. We recommend using the pie when the progression is predefined in a series of stops that the user has to go through in order to achieve completion.

## Pie vs. Progress Bar

Pie Chart and Progress Bar serve different mental models and UX contexts.

| Criterion | Pie Chart | Progress Bar |
| --- | --- | --- |
| Core purpose | Visualizes a fraction of something. | Shows linear progression along a defined path or process. |
| Mental model | Feels cyclical, looped, or holistic — completion "closes the circle." | Feels sequential or directional — progress "moves forward." |
| Use when... | You want to show a fraction of something (i.e. 3/6 steps done); you're comparing few, independent progress values. | You need precise readability and users care about the actual numeric progress; you want to provide more context through labels. |

## Properties

| Property | Details |
| --- | --- |
| Type | Default / Branded / Success / Alert / Error / Neutral — color of the segments. **Default** is generic progression used when the increment or completion isn't meant to show a positive or negative feeling. **Branded** is an alternative to Default. **Success** shows a positive feeling for any increment or completion. **Alert** shows a possible stall for the completion. **Error** shows a negative feeling for any increment or lack of completion. **Neutral** is the inactive or locked state of the progression itself. |
| Secondary label | String explaining what the main label shows. |
| Main label | String showing the bar value. |
| Progression | Value determining how much progress the pie should display. |
