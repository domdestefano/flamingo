# Pie Chart <StatusBadge status="stable" />

Indicates a sectioned progression in a circular shape, e.g. tasks completed out of a total.

## Properties

| Property | Details |
| --- | --- |
| Type | Neutral / Default / Success / Alert / Error / Branded — color of the segments. |
| Main label | The primary value, e.g. a fraction like "6/7." |
| Secondary label | Supporting text below the main label, e.g. "Value." |
