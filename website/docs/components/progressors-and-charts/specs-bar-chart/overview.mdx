## Properties

| Property | Details |
| --- | --- |
| # of Bars | The number of bars shown. |
| Selected bar | Which bar (if any) is tapped/highlighted. |
| Show Tooltip | Optional — shows a value tooltip above the selected bar. |
| Show Goal line | Optional — shows a dashed reference line across the chart. |
