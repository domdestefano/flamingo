## Properties

| Property | Details |
| --- | --- |
| # of bars | The overall amount of bars the chart should display. |
| Selected bar | A bar, which is tapped. If this is "none" it means that no bar is being currently tapped. |
| Showing a tooltip | Option to show a tooltip above a bar to indicate the value of the bar. |
| Showing a goal line | Option to show a goal line across the graph. |
| Bar amount | The amount each bar should display. |

## Anatomy

<ComponentImage src="/img/components/specs-bar-chart/specs-bar-chart-anatomy.png" alt="Bar chart anatomy: Tooltip, Bars, Goal line, Labels" />

1. **Tooltip** — it displays the current value of the bar that the user tapped on.
2. **Bars** — can be resting or tapped on. Each bar can have a unique value.
3. **Goal line** — it describes what the goal amount is.
4. **Labels** — explain what each bar shows.

## Interactions

### Tapping a bar

The whole height of the bar can be tapped on. When tapping on a bar is enabled, the bar is:

- highlighted
- displays a tooltip (optional)
