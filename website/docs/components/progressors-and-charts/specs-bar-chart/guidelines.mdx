## Usage

- Use the bar chart to compare data to one another.
- Add ideally a tooltip property and show the value for each graph a user taps on.

## Placement

The more bars the chart has, the more horizontal space it should get to ensure labels can be
read. Place it therefore ideally without any other elements left or right besides it. Avoid
placing it on cards.

## Use cases

### Label text & translations

Be always mindful of the labels text length. Use abbreviations if necessary to ensure all labels
can be read. Keep labels line height at 2 max.

### Width

Be cautious when resizing the component. The more bars it has, the more horizontal space it
should have, so users can properly interact with it.

<ComponentImage src="/img/components/specs-bar-chart/specs-bar-chart-width-do.png" alt="Bar chart using the full width of the screen" />

Use ideally the full width of the screen.
