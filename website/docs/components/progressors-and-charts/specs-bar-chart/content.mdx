## Guidelines

The bar chart uses copy in the **tooltip** and in the **labels**:

- The tooltip is always one line.
- Each label can display several lines. However, keep the number of lines consistent across all labels in the graph.
- The space of labels is very limited, esp. if there are many bars. Try to write as short as possible labels and consider how they would get translated (e.g. instead of January, February, March, … you could use J, F, M).

## Truncation behaviour

There's currently no truncation behaviour.
