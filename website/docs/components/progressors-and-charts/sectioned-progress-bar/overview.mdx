# Sectioned Progress Bar <StatusBadge status="stable" />

Represents a progression fractioned into milestones — each milestone is a stop the progression
must pass through to reach completion.

## Properties

| Property | Details |
| --- | --- |
| # of Milestones | The number of milestones in the bar. |
| Progression | Which milestone is currently active. |
| Milestone indicator | Icon / Number — how each milestone is represented. |
| All Milestones with Icons | Optional — whether every milestone gets an icon, not just the active one. |
| Show Labels | Optional — toggles labels below each milestone. |
| Mid progress | Whether progress is shown partway between two milestones. |
