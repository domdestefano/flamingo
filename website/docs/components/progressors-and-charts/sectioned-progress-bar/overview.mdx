## Description

The sectioned progress bar is used to represent a progression, fractioned in milestones. Each
milestone represents a stop the progression needs to go through in order to achieve completion.

It's usually used to:

1. Show progress on a challenge (i.e. quest).
2. Show progress in a multi page flow (i.e. sign up flow).

When using this component in your design, think about the behaviour in three states:

| State | Details |
| --- | --- |
| Start | The user is still at the starting point. Ask yourself if the start should be part of the progression or not. |
| Ongoing | The user has made some progress. Decide whether you want to keep a neutral character or indicate whether they're on or off track. |
| Completed | The user finished. Decide whether you want to keep a neutral character or indicate success. |

## Properties

| Property | Details |
| --- | --- |
| Type | **Default**: visually a neutral character, used in most cases. **Alert**: use to indicate something needs attention. **Error**: use to indicate something is not on track or needs attention. **Success**: use to indicate something is on track or finished. **Inactive**: use to indicate that it's over or currently not working. |
| # of Milestones | Amount of milestones displayed (1–10). |
| Progression | Amount of progress, from 0–100%. |
| Start Marker Active | **No**: marker displayed in the color of an inactive bar, to indicate progress is exactly 0. **Yes**: marker displayed in the color of an active bar, to indicate something has already been reached or the user is on a particular step. |
| Show All Icons | **No**: only the current and final milestone have an icon. **Yes**: all milestones display an icon. |
| Mid Progress | Shows a progression continuing over the milestone marker. |
| Icons or Numbers | Choose numbers or icons to show progression. |
| Display Labels | **No**: labels hidden. **Yes**: labels visible. |
| Labels | String — the label of each milestone. |

## Sectioned progress bar vs. Progress bar

The sectioned progress bar shows progress in milestones, letting the user understand that they
have to go through a series of steps to reach completion. It's providing more visual clues.

The progress bar, instead, shows general progress in a continuous way, meaning the user doesn't
have to reach any milestones in order to achieve completion.

## Sectioned progress bar vs. Stepper

Steppers are an interactive element that users can interact with. They display content attached
to each step that a user needs to do.

The sectioned progress bar is an element the user cannot directly interact with. It only gives an
indicator on the progress.
