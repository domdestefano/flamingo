## Component

Each row pairs a title (plus optional subtitle) with a trailing chevron, signalling that tapping
the row navigates to another screen — e.g. a settings row like "Time" or "Preferred Chat Language".

This component's Figma spec doesn't yet include an Overview/Anatomy breakdown — only Usage
examples. If one gets added to Figma, register its frame and update this section rather than
