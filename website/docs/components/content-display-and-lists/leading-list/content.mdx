# Content

<ComponentTabs basePath="/components/content-display-and-lists/leading-list" />

Row titles should name the destination or setting clearly and concisely — a user should know
exactly where tapping the row will take them before they tap it.

- Keep titles short enough to fit on one line where possible; if translation makes a title wrap to
  two lines, that's expected and fine — don't shrink the text or truncate it to force one line.
- An optional subtitle can show the current value (e.g. "English" under "Preferred Chat Language").
