## Do's and Dont's

### "Show all" cards

Cards are very prominent UI elements; this means that you shouldn't unnecessarily overload the UI
with them. You can use the "Show all" card in order to avoid UI clutter and lead to a screen
dedicated to all the listed items you want to link the user to.

<DoDontTable
  doText='Avoid long and infinite scrolling with cards by having a "Show all" card that leads to all other listed items.'
  dontText="Don't have a large number of cards in a horizontal scroll view."
/>

### Buttons in cards

Buttons should follow the general guidelines for buttons: use a primary button only for the most
important action, and secondary/tertiary for the remaining ones. You can also have a card with only
a primary button, when showing multiple cards.

<DoDontTable
  doText="Use a primary button only for the most important action card, secondary/tertiary for the remaining ones."
  dontText="Don't use multiple primary buttons within cards that follow the same hierarchy as other buttons."
/>
