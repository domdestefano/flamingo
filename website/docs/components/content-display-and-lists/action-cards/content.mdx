# Content

<ComponentTabs basePath="/components/content-display-and-lists/action-cards" />

The main label (title) should name the item being listed clearly and concisely — it's the
mandatory piece of information a user relies on to identify the card. The button label should
follow standard button-copy guidelines (short, **action + noun** format, e.g. "Book shift").

The optional caption text should add genuinely useful detail about the listed item — don't pad it
just to fill space in the card.
