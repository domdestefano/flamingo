# Content

<ComponentTabs basePath="/components/content-display-and-lists/accordion" />

The collapsed title and description should already convey what's inside — a user should be able to
decide whether to expand the accordion without needing to open it first. Keep the collapsed
description short (max 2 lines) and specific about what will be revealed.

## Truncation

Both the title and description support a maximum of 2 lines while collapsed — truncate with an
ellipsis (…) rather than wrapping indefinitely or overflowing the row.
