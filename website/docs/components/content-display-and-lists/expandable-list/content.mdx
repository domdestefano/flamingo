# Content

<ComponentTabs basePath="/components/content-display-and-lists/expandable-list" />

The collapsed row should already convey the most important information (what the item is, its
status) — the expanded content is supplementary detail, not the only place key information lives.

- Keep expanded content scannable: short labels paired with values, not paragraphs.
- Only include detail that's genuinely useful to check — don't pad the expanded area to make the
  row feel more substantial.
