## Component

Each row can be expanded independently to reveal additional detail relevant to that specific item
— for example, a delivery's distance, cash collected, and tips — then collapsed again once read.

This component's Figma spec doesn't yet include an Overview/Anatomy breakdown — only Usage
examples. If one gets added to Figma, register its frame and update this section rather than
inventing an anatomy list.
