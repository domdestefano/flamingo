# Content

<ComponentTabs basePath="/components/content-display-and-lists/simple-list" />

The main label should clearly name the item being listed — it's the mandatory piece of
information a user relies on to identify the row. The optional description text should add
genuinely useful detail, not padding.

If a button is present, follow standard button-copy guidelines (short, **action + noun** format,
e.g. "Book shift") — simple list buttons are always tertiary style, small.
